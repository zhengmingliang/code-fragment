# 标准借条生成器 (Standard IOU Generator)

一个基于纯前端技术打造的**律师级标准借条生成器**。旨在帮助用户快速、规范地生成具有法律效力的借条，同时 100% 保护用户隐私。

## 核心功能

*   **律师级专业条款**：内置完善的法律条款，包含借款用途、转账账户、合法利息（LPR 4倍提示）、逾期责任、维权费用（诉讼费、律师费等）承担以及法定送达地址确认，完美规避常见法律漏洞。
*   **纯前端运行，绝对隐私**：无任何后端服务器，无数据库。所有数据仅存在于用户的浏览器中，绝不上传，从根本上杜绝身份证号、银行卡号等敏感信息泄露。
*   **独创“加密”分享**：支持将已填写的部分信息（如出借人信息、金额）通过 Base64 编码压缩生成专属 URL 链接。发送给对方后，对方打开链接即可继续补充信息，免去当面填写的尴尬。
    *   *附带智能降级复制方案，兼容局域网等非 HTTPS 环境。*
*   **完美适配 A4 打印**：针对浏览器的打印功能进行了像素级优化。自动调整字号、行距和下划线宽度，确保无论填写多少内容，借条正文及最后的签字画押区都能完美收纳在一张 A4 纸上。
*   **金额自动大写**：输入阿拉伯数字金额，自动转换为规范的人民币大写金额，防止篡改。

## 本地运行

1. **克隆项目**
   ```bash
   git clone https://github.com/zhengmingliang/code-fragment.git
   cd code-fragment/html/jietiao
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```
   启动后，在浏览器中访问 `http://localhost:3000` 即可预览。

## 编译与部署

本项目为纯静态前端项目，打包后可部署到任何静态资源服务器（如 Nginx, GitHub Pages, Vercel, Netlify 等）。

### 常规部署（部署到域名根目录 `/`）

```bash
npm run build
```
构建完成后，将 `dist` 目录下的所有文件上传到您的服务器即可。

### 子目录部署（部署到指定路径，如 `/iou/`）

如果您希望将项目部署在网站的子目录下，可以在打包时通过环境变量 `BASE_PATH` 指定路径：

**方式一：命令行指定**
```bash
# Mac / Linux
BASE_PATH=/iou/ npm run build

# Windows (CMD)
set BASE_PATH=/iou/ && npm run build

# Windows (PowerShell)
$env:BASE_PATH="/iou/"; npm run build
```

**方式二：使用 `.env` 文件（推荐）**
在项目根目录创建 `.env` 文件，并添加以下内容：
```env
BASE_PATH=/iou/
```
然后直接运行 `npm run build` 即可。生成的 `dist` 目录中的静态资源路径会自动加上 `/iou/` 前缀。
