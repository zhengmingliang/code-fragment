# Git 提交时间修改工具

`git-change-commit-time.sh` 用于修改一个或多个 Git 提交的时间戳，支持交互模式和命令行模式。

支持两种修改方式：

- **绝对时间**（`-d`）：替换为指定的日期/时间。
  - `YYYY-MM-DD`：仅替换日期，原时分秒保留。
  - `YYYY-MM-DD HH:MM:SS`：完整替换作者时间与提交者时间。
- **相对偏移**（`-o`）：在每条选中提交各自原有的时间基础上加减天/小时/分钟，例如 `+1d`、`-3h`、`+2d-3h+15m`。

两者互斥，不指定时进入交互模式现场选择。

最简单的用法是直接运行脚本，按提示选择提交、选择修改方式并输入对应的值：

```bash
./git-change-commit-time.sh
```
